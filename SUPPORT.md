# Support / 获取帮助

## Find the right project

- [Matrix](https://github.com/xova-dev/matrix): see the [documentation](https://xova-dev.github.io/matrix/) for multi-app workspace tooling.
- [Actions](https://github.com/xova-dev/actions): see the [project workflow guide](https://github.com/xova-dev/actions/blob/main/docs/project-workflows.md) for shared CI and release tooling.
- [Organization defaults](https://github.com/xova-dev/.github): use this repository only for shared templates, policies and organization profile feedback.

Read the project's README and search existing issues first. Submit bugs and feature requests in that project's Issues using the Chinese or English form. For usage questions or documentation feedback that do not fit a form, open a blank issue with your goal, relevant context and what you have tried. Remove credentials and private data.

For security vulnerabilities, use [private reporting](https://github.com/xova-dev/.github/blob/main/SECURITY.md), not a public issue. For code contributions, read the [contributing guide](https://github.com/xova-dev/.github/blob/main/CONTRIBUTING.md) and any project-specific instructions.

## 找到对应项目

- [Matrix](https://github.com/xova-dev/matrix)：多应用工作区工具，先查看[项目文档](https://xova-dev.github.io/matrix/)。
- [Actions](https://github.com/xova-dev/actions)：共享 CI 和发布工具，先查看[工作流接入指南](https://github.com/xova-dev/actions/blob/main/docs/project-workflows.zh-CN.md)。
- [组织默认配置](https://github.com/xova-dev/.github)：此仓库仅处理共享模板、政策和组织首页相关反馈。

请先阅读项目 README 并搜索已有 Issue。Bug 和功能建议请在对应项目的 Issues 中选择中文或英文表单。不适合现有表单的使用问题、文档反馈可以新建空白 Issue，说明目标、相关背景和已尝试的方法。请移除凭据和私密数据。

安全漏洞请通过[私密渠道](https://github.com/xova-dev/.github/blob/main/SECURITY.md)报告，不要公开提交。参与代码贡献前，请阅读[贡献指南](https://github.com/xova-dev/.github/blob/main/CONTRIBUTING.zh-CN.md)及项目专属说明。

# Xova

Open-source tools for TypeScript workspaces and shared delivery workflows.
面向 TypeScript 工作区与共享交付流程的开源工具。

- [Matrix](https://github.com/xova-dev/matrix) — Configuration-driven CLI for running and packaging multi-app workspaces. / 配置驱动的多应用工作区运行与打包工具。
- [Actions](https://github.com/xova-dev/actions) — Reusable CI, release and documentation workflows. / 可复用的 CI、发布和文档工作流。
